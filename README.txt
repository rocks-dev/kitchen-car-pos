キッチンカーPOS PWA-2
完全オフライン起動＋オフライン商品/チケット編集対応

追加機能:
・ネットなしでも商品を新規登録・編集・削除
・ネットなしでもチケットを新規登録・編集・削除
・商品名、価格、税率、表示順、対応チケット、表示色を端末内で変更
・変更は即レジ画面に反映
・変更内容は「未同期」に入り、ネット復旧時にGoogleスプレッドシートへ同期
・商品/チケット変更を先に同期してから売上を同期
・同期後はGoogle側の最新マスタを再取得

導入:
1. GASのCode.gsを「①Code.gs_PWA2_オフライン商品編集同期対応.txt」に上書き
2. 新しいバージョンでデプロイ
3. pwaフォルダの中身をGitHub Pages等へ上書き
4. PWAをオンラインで一度開く
5. service worker更新のため、必要ならアプリを一度閉じて再起動
6. 「商品・チケット管理」からオフラインでも編集可能

注意:
複数端末が同時にオフラインで同じ商品を別々に変更した場合、後から同期した変更がGoogle側では優先されます。
